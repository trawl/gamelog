Gamelog
=======

Simple application to keep record of board game results.

## Running Gamelog

The easiest is through [uv](https://github.com/astral-sh/uv). Once installed in your system, clone or download this repository and then run the following on the command line from the root of the project:

```
uv run gamelog.pyw
```

Platforms supported: MacOS, Linux and Windows.
